# Borealis Mockups

This directory contains the Borealis HTML prototypes and related mockup assets used as the visual reference for implementation.

## Primary Reference

- `borealis-prototype.html` — the canonical Borealis prototype containing all 15 designed pages from the workshop session

## How to Use the Prototype

1. Open `borealis-prototype.html` in a web browser.
2. Scroll through the document from top to bottom.
3. Use the page separators and labels to review each designed screen in sequence.
4. Compare implementation work against this file for layout, hierarchy, spacing, component treatment, and state handling.

## What It Includes

- 7 customer-facing pages
- 8 admin-facing pages
- the mobile viewport validation frame
- the approved colour, typography, and component direction for Borealis

## Recommended Workflow

- Use the prototype as the first visual check before building a page.
- Revisit it when implementing states such as loading, success, validation errors, and expiry handling.
- Treat it as a visual reference, not production code.

## Important Notes

- The prototype is the **canonical visual reference** for Borealis.
- It should be used alongside `docs/design-brief.md` and `.impeccable.md`.
- If implementation details and the prototype disagree, resolve the work in favour of the approved Borealis design direction captured in those references.
